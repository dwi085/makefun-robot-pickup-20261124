An entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on [make.fun](https://make.fun).

`main.ts` (Node 22) writes exactly one line — a pickup line in the voice of a robot trying to charm someone — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: two runs produce byte-identical output. No network, no randomness, exit 0.

The line: a robot that ran a million simulations of meeting you, and still forgot to say hello first.
